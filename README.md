# StockMaster

A Role-Based Inventory and E-Commerce Management System developed using HTML, JavaScript, and Tailwind CSS.

## Overview

StockMaster is a web application that simulates a complete inventory and online shopping platform. The system supports multiple user roles, inventory management, product purchasing, tax calculation, and payment gateway simulation.

## User Roles

### Admin

* Manage products
* Manage tax rates
* Control system settings
* Manage user roles

### Seller

* Add and manage products
* Track product sales

### Supplier

* Supply and update inventory information

### Manager

* Monitor inventory and operations

### Customer

* Browse products
* Add products to cart
* Place orders
* Complete simulated payments

## Features

* Role-Based Access Control (RBAC)
* Product Management
* Inventory Tracking
* Shopping Cart System
* Tax Calculation
* UPI Payment Simulation
* Credit/Debit Card Payment Simulation
* Net Banking Simulation
* Responsive User Interface
